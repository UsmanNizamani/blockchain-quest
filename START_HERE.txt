  BLOCKCHAIN QUEST — START HERE
=========================================

Thank you for checking out Blockchain Quest!

TO PLAY THE GAME:

  1. Install Node.js (one-time, 30 seconds)
     -> https://nodejs.org
     -> Download the LTS version
     -> Install with all default options

  2. Launch the game:
     -> Windows:  Double-click "Launch Game.bat"
     -> macOS:    Double-click "Launch Game.command"
     -> Linux:    Double-click "Launch Game.sh"
                 (or run: ./Launch Game.sh)

  3. The game opens in your browser at:
     -> http://localhost:3000

TO STOP THE GAME:
  Close the black terminal window.

HAVING TROUBLE?
  See TROUBLESHOOTING.md
  Or open an issue: https://github.com/UsmanNizamani/blockchain-quest/issues

Enjoy!
